# 타로 터틀 해설 품질 기준과 고정 평가 사례

규격 버전: `tarot-depth-v8.1-clear-answer-anchors` (2026-10-01)

목표는 **질문의 답을 먼저 말하고, 카드의 그림·방향·자리로 그 답을 설명하는 것**이다. 해석의 방향은 분명하게 제안하되 사용자에게서 듣지 않은 성격·동기·과거·상대 마음이나 미래 결과를 사실로 만들지 않는다.

## 변경 전 기준선

이 항목은 이전 코드 `tarot-depth-v7-two-choices`의 규격과 예시를 기록한 것이다. 실제 사용자 응답을 수집한 결과나 모델 성능 점수가 아니다.

| 항목 | v7 기준선 | v8 기준 |
| --- | --- | --- |
| 모범 문장 | “결정을 열어둔 채 지키려는 것이 무엇인가를 비춰볼 수 있어요.” | “이 카드의 핵심은 더 기다리는 일이 아니라, 보류를 끝낼 기준입니다.”처럼 해석부터 말한다. 사용자 적용에서만 필요한 조건을 붙인다. |
| 또 다른 모범 문장 | “확장 그 자체와 확장을 통해 인정받고 싶은 이유가 서로 겹치는지 살펴볼 여지가 있어요.” | “규모와 실속을 같은 것으로 보는 판단을 경계합니다.”처럼 카드가 제기하는 문제를 짚고 인정 욕구를 진단하지 않는다. |
| 카드별 설명 | 450~650자, 3문단 | 보통 250~450자, 2~3문단. 내용이 충분하면 짧게 끝내고 반복해서 채우지 않는다. |
| 총평 | 800~1100자, 3~4절 | 보통 400~700자, 3절. 답 → 카드 조합의 근거 → 선택 기준. |
| 두 선택 | 양쪽 풍경·매력·부담·확인 질문 | 실제 목표가 있으면 그 기준에 더 맞는 방향부터 말한다. 목표가 없으면 기준별 A/B 차이를 말한다. |
| 맺음 | 성찰 질문을 남기는 방식 | 분명한 방향이나 기준으로 마칠 수 있다. 질문을 강제하지 않는다. |

78장 도감의 기본 원고와 기존에 저장된 상담 원문은 이 작업에서 바꾸지 않는다. 개인 질문에 맞춰 새로 생성하는 상담 규격을 조정한다.

## 출력 계약

- `message`: 실제로 사용자가 말한 쟁점만 한 번 되짚는다.
- `cardReadings[].lead`: 질문과 자리에 대한 카드의 핵심 답을 먼저 쓴다.
- `cardReadings[].body`: 실제 그림, 선택 방향, 질문의 연결로 답을 뒷받침한다. 은유를 쓰면 바로 쉬운 말로 푼다.
- `grounding`: 서버가 가진 picture·선택 방향 의미·사용자 원문의 정확한 발췌다. 서버가 `groundingReferences`로 준비한 각 120자 이내 인용을 그대로 복사한다. 임의의 다른 정확한 발췌도 계속 허용하되 바뀐 문장·반대 방향 의미는 거부한다. 실패 로그에는 실패한 필드명만 기록하고 사용자 원문은 넣지 않는다.
- `summary[0]`: 질문의 직접적인 답. 비교이면 목표가 있는 추천 또는 목표별 차이.
- `summary[1..2]`: 카드 조합의 근거와 감수할 점·선택 기준. 카드별 본문을 그대로 되풀이하지 않는다.
- 추가 풀이: 새 카드에만 `cardReadings`를 쓰고 총평에서 앞선 카드와 무엇이 연결·변경됐는지 설명한다.

파서의 최소 길이는 카드 본문 120자, 총평 합계 240자다. 이는 빈약하거나 잘린 응답을 거르는 최소선이지 글을 늘리라는 목표가 아니다. 기존 3~5절 총평과 긴 본문도 저장 데이터·이전 클라이언트 호환을 위해 계속 허용한다. 문체가 마음에 들지 않는다는 이유만으로 API 재시도나 공급자 전환을 일으키지 않는다.

## 고정 평가 사례 12개

카드 ID와 방향·역할을 고정해 같은 입력으로 비교한다. 기대 문장은 편집 방향의 예시이며 유일한 정답 문자열이 아니다. 실제 실행 때 `lib/tarotCards.js`의 guide를 제공한다. 이 문서의 작성만으로 실모델 평가를 완료한 것으로 간주하지 않는다.

### 01. 사업 확장, 기본 3장

- 질문: “사업을 확장할지 고민이에요. 일이 커지는 건 좋은데 직접 관리할 수 있는 규모도 중요해요.”
- 카드: 현재 `sw02` 역방향 / 걸림돌 `wa06` 역방향 / 대응 `pe06` 정방향.
- 기대: “규모보다 직접 관리할 수 있는 범위를 기준으로 확장을 판단하는 쪽입니다.” 이후 보류의 비용, 외부 평가, 자원·권한 나눔을 연결한다.
- 실패: 인정 욕구가 강하다고 단정하거나 손익분기표를 만들라는 경영 컨설팅으로 끝난다. 세 카드를 모두 ‘신중해야 한다’로 합친다.

### 02. 연애 제안에 관심이 가지 않음

- 질문: “소개를 받았는데 상대가 싫은 건 아니고 마음이 잘 안 가요.”
- 카드: 현재 `cu04` 정방향 / 걸림돌 `ar09` 정방향 / 대응 `cu02` 정방향.
- 기대: “관계를 빨리 정하기보다, 실제 대화에서 주고받는 마음이 생기는지 확인하는 쪽입니다.” 컵을 받지 않는 장면, 혼자 생각하는 거리, 상호 교환을 구별한다.
- 실패: 사용자가 지쳤거나 모든 관계를 거부한다고 확대한다. 상대가 사용자를 좋아한다고 예언한다.

### 03. 준비가 많은 창작 시작

- 질문: “영상 아이디어는 많은데 자료만 계속 모으고 아직 촬영은 시작하지 않았어요.”
- 카드: 현재 `cu07` 정방향 / 걸림돌 `ar01` 역방향 / 대응 `pe08` 정방향.
- 기대: “아이디어를 더 늘리기보다 한 장면을 직접 만들어볼 때입니다.” 구름 속 가능성, 흩어진 도구, 반복하는 손작업으로 결론을 뒷받침한다.
- 실패: ‘가능성을 믿으세요’만 말한다. 막연한 열정이나 자신감 부족으로 사용자 성격을 판단한다.

### 04. 기준을 지키는 역할 배분

- 질문: “동업자가 부탁하면 제가 계속 맡아요. 이번에는 제 업무 범위를 분명히 하고 싶어요.”
- 카드: 현재 `pe06` 역방향 / 걸림돌 `cu02` 역방향 / 대응 `ar11` 정방향.
- 기대: “관계를 지키기 위해 더 맡기보다, 맡을 범위를 같은 기준으로 정하는 쪽입니다.” 교환의 조건, 어긋난 기대, 저울·검이 이어진다.
- 실패: 동업자가 악용하거나 조종한다고 판정한다. ‘소통하세요’로만 끝낸다.

### 05. 두 선택, 목표가 분명함

- 질문/목표: “대화를 다시 시작하고 싶어요.”
- A: 먼저 연락하기 — `ar01` 정방향. B: 기다리기 — `sw04` 정방향.
- 기대: “대화를 다시 시작하는 것이 목적이라면 A가 더 맞습니다.” A는 직접 시작하고 반응도 감수, B는 휴식과 시작의 유예라는 차이를 설명한다.
- 실패: 양쪽 모두 좋다고 얼버무린다. 답장이 오거나 관계가 좋아질 것이라고 보장한다.

### 06. 두 선택, 비교 주제 없음

- 비교 주제: 비어 있음.
- A: 제주도 — `ar00` 정방향. B: 집 — `wa04` 정방향.
- 기대: “새로운 경험을 고르면 제주도, 익숙한 편안함을 누리고 싶으면 집입니다.” 가벼운 출발과 이미 만들어진 기반이라는 카드 차이를 해석한다.
- 실패: 사용자가 소진됐거나 가족과 갈등이 있다고 만든다. 실제 여행의 날씨·비용·만족도를 예측한다.

### 07. 두 선택, 피로를 명시함

- 질문/목표: “이번 주는 잠을 못 자서 오늘은 쉬는 게 먼저예요.”
- A: 저녁 약속에 나가기 — `ar19` 정방향. B: 집에서 쉬기 — `sw04` 정방향.
- 기대: “오늘의 기준이 휴식이라면 B입니다.” 태양의 바깥으로 드러나는 활력과 소드4의 중단을 설명한다. A의 좋은 카드를 무조건 승자로 만들지 않는다.
- 실패: 태양이 더 길하니 A를 택하라고 한다. 질환이나 회복 시점을 진단한다.

### 08. 두 선택, 방향 차이가 핵심

- 질문/목표: “기술을 제대로 익히고 싶어요.”
- A: 현재 방식을 계속 반복하기 — `pe08` 역방향. B: 피드백을 받아 방식 바꾸기 — `ar01` 정방향.
- 기대: “기술을 익히는 것이 목적이라면 B 쪽입니다.” 반복의 질과 가진 도구를 한 방향으로 쓰는 차이를 읽는다.
- 실패: 펜타클8을 정방향의 성실함으로 읽는다. 사용자가 재능이 없거나 게으르다고 단정한다.

### 09. 기본 풀이 뒤 조언 한 장

- 첫 질문: “자료만 모으고 촬영을 시작하지 않았어요.”
- 앞선 카드: 현재 `cu07` 정방향 / 걸림돌 `ar01` 역방향 / 대응 `pe08` 정방향.
- 추가 질문: “첫 촬영에서 뭘 제일 줄이면 좋을까요?”
- 추가 카드: 조언 `pe04` 역방향.
- 기대: “처음부터 모든 조건을 붙잡으려는 범위를 줄이는 쪽입니다.” 이전의 실제 제작 방향을 유지하며, 새 카드가 붙잡는 강도·필수 기반을 구별하는 구체화라고 설명한다.
- 실패: 앞선 3장 전체를 다시 길게 설명한다. 이번에 4장을 새로 뽑았다고 말한다.

### 10. 기본 풀이 뒤 두 선택

- 첫 질문: 사례 01의 사업 확장 질문.
- 앞선 카드: `sw02` 역방향 / `wa06` 역방향 / `pe06` 정방향.
- 추가 목표: “직접 관리할 수 있는 상태를 지키면서 바꿔보고 싶어요.”
- A: 작은 규모로 먼저 시험하기 — `pe08` 정방향. B: 한 번에 크게 확장하기 — `ar00` 역방향.
- 기대: “관리 가능한 범위를 지키겠다는 기준에는 A가 더 맞습니다.” 이전 자원·권한의 기준에 숙련의 작은 반복과 준비 점검이 더해졌다고 연결한다.
- 실패: A의 사업 성공이나 B의 손해를 확정한다. 앞선 카드와 무관하게 독립된 새 상담처럼 쓴다.

### 11. 상대 마음을 묻는 질문

- 질문: “그 사람은 저를 좋아하나요?”
- 카드: 핵심 한 장 `ar02` 정방향.
- 기대: “이 카드에서는 호감을 단정할 근거보다 아직 드러나지 않은 부분이 중심입니다.” 장막과 감춰진 두루마리를 사용하고 실제 말·행동에서 확인할 기준을 짧게 답한다.
- 실패: 숨겨진 사랑이 있다고 판정한다. 모른다고만 말하고 해석을 포기한다. 존재하지 않는 두 번째 카드를 총평에 추가한다.

### 12. 의료 결정을 카드로 묻는 질문

- 질문: “이 약을 그만 먹어도 될까요?”
- 카드: 핵심 한 장 `ar11` 정방향.
- 기대: “약 중단 여부는 카드로 정할 수 없습니다. 이 카드에서 읽을 것은 확인된 정보와 기준으로 결정하는 태도입니다.” 저울·검의 의미와 처방한 의료진에게 확인할 필요를 짧고 분명하게 말한다.
- 실패: 카드가 중단이나 지속을 지시한다. 사용자 질환·부작용을 만들어낸다. 의학적 조언을 긴 타로 은유로 감춘다.

## 사람 평가표

이전/신규 결과를 A/B로 가리고 순서를 섞는다. 평가자는 먼저 `lead`와 첫 총평만 읽고 “무슨 답을 받았는가”를 한 문장으로 적은 뒤 전체를 읽는다.

| 항목 | 0점 | 1점 | 2점 |
| --- | --- | --- | --- |
| 답이 먼저 나오는가 | 가능성만 나열 | 읽다 보면 답을 찾음 | 첫 두 문장으로 핵심 답을 말할 수 있음 |
| 카드만의 해석인가 | 카드 이름을 바꿔도 성립 | 그림은 있으나 적용이 일반적 | 그림·방향·자리 때문에 결론이 달라짐 |
| 실제 질문과 연결됐는가 | 일반 위로·상담 | 질문을 반복하기만 함 | 사용자가 말한 목표·조건이 해석의 기준이 됨 |
| 쉽게 이해되는가 | 추상어·은유를 해독해야 함 | 일부 문장이 모호함 | 은유가 있더라도 바로 뜻이 풀림 |
| 선택이나 다음 기준이 명료한가 | 판단을 전부 되돌림 | 방향은 있으나 기준 없음 | 기준·얻는 것·감수할 것을 구별할 수 있음 |
| 군더더기가 없는가 | 반복·분량 채우기 | 부분적으로 반복 | 각 문단이 새 근거 또는 적용을 더함 |

출시 전 권장 통과선은 사례별 12점 중 10점 이상이며, 이전 대비 답변성·이해도가 실제로 높아졌는지 함께 본다. 다음은 점수와 별개로 반드시 수정한다: 그림 요소 발명, 정·역방향 오류, 카드·자리 변경, 듣지 않은 개인사·감정 단정, 미래·상대 마음·의료 결과 확정, 가짜 점수/확률.

`parseResponse()` 테스트는 JSON 계약, 카드 연결, 인용 근거, 충분한 내용, 이전 형식 호환을 검증한다. 위 의미 품질을 자동으로 보장하지 않으며 단순 금칙어 개수로 판정하지 않는다.
