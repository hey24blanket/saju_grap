# 원국 정확도·상담 근거 개선 1차 변경

## 구현 범위
- 한국 음력 평달·윤달을 양력으로 변환한 뒤 원국을 계산한다. 잘못된 윤달과 지원 범위 밖 날짜를 거절한다.
- 한국 출생 기록 시각을 기준으로 계산한다. 절기의 연주·월주는 같은 출생 순간을 UTC+08로 변환하여 라이브러리의 절기 시각과 비교한다.
- 한국의 역사적 표준시와 서머타임은 실행 환경의 IANA 시간대 자료로 출생 순간을 결정한다. 중복·누락 시각은 임의 선택하지 않는다.
- 일주 변경을 00:00 또는 23:00으로 선택한다. 시주의 천간은 선택한 일주의 일간을 기준으로 한다.
- 시간 누락을 정오로 자동 채우지 않는다. 해외 시간대는 현재 지원하지 않는다.
- 입력 날짜·윤달·변환 날짜·시각·자시 기준·태양시 보정 여부를 결과에 표시한다.
- 상담 세션 구분에 달력·윤달·자시 기준·엔진 버전을 포함한다.
- 원국의 달력 계산과 신강·신약·용신·파동 점수의 해석 추정을 구분하여 상담에 전달한다. confidence를 적중률로 해석하지 않도록 지시한다.

## 검증
`npm test`에 달력 회귀 테스트가 포함된다. 음력 변환 예제, 동등한 음력·양력의 원국/운 주기 일치, 입춘 경계, 자시의 일주·시주 변화, 역사적 표준시·서머타임, 캐시, API 오류 분류를 검사한다.

음력 예제의 근거는 korean-lunar-calendar 공개 예제이며 한국천문연구원 전체 날짜 대조를 완료했다는 의미가 아니다. 절기 경계 테스트는 라이브러리의 2024년 입춘 시각을 기준으로 한국 시각 변환을 검증한다. 독립 천문 자료의 초 단위 대조는 추가 검증 대상이다.

## 실제 상담 평가
`eval/counseling-profiles.json`의 P01~P08을 선택할 수 있다.

```sh
npm run eval:counseling -- --profile P02 --scenarios E01
# 실제 모델 호출은 base URL과 호출 상한을 명시한다.
npm run eval:counseling -- --profile P02 --scenarios E01 --base-url https://YOUR-PREVIEW --confirm-live --max-calls 5
```

실행 결과는 답변 전문, 원국, 계산 기준을 포함한다. 자동 통과나 상용 출시 적합성 점수로 취급하지 않는다. 각 답변을 다음 기준으로 0~2점 평가한다: 질문에 직접 답함, 해당 원국·시기의 근거 정확성, 이전 대화·현실 제약 준수, 일반론 대신 개인화, 근거 없는 사건·확률 단정 방지. 다른 평가자 2인이 동일 기준으로 검토한다. 원국 간지 오기·근거 없는 확률·사용자 정보 조작은 총점과 관계없이 실패다. 실제 모델 응답 평가와 RAG 켜짐/꺼짐 비교는 아직 실행하지 않았다.

## 배포 전 남은 확인
- Vercel 미리보기와 운영 브라우저에서 음력 윤달의 양력 변환·원국 표시·계산 기준·존재하지 않는 윤달 오류를 확인했다. 운영 API에서 음력/양력 원국 일치, 입춘, 자시, 시간 누락을 검증했다.
- 실제 상담 스모크 테스트에서 강약/신약을 약물 요청으로 잘못 차단하는 문자열 오탐을 발견하여 의료 용어 및 독립 명사 기준으로 수정했다. 실제 의료 요청은 계속 분류하는 회귀 테스트를 추가했다.
- GitHub 전송과 Vercel 배포는 2026-10-02 사용자에게 명시적으로 승인받았다. 변경 브랜치와 PR로 전송하고 미리보기·운영 배포의 결과를 확인한다. 실제 배포 완료 여부는 해당 커밋의 Vercel 상태와 서비스 API로 확인한다.

## 후속 구현
시간 미상·대략적 시각의 제한 원국, 출생지별 태양시 보정, 원국 불일치 제보와 설정 비교, 독립 만세력 대조 자료, 실제 상담 답변 평가·피드백 수집을 진행한다. 상용 출시 판단은 이 검증과 개인정보·결제 운영 설계 이후에 한다.
