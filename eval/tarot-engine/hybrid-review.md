# 해석·작성 모델 분리 검토

Sol 단일 생성은 첫 미사용 10개 질문에서 직접성과 사실 구분을 만족했으나, 그림 회귀 사례에서 '제 스타일'이라는 화자 오류가 다시 발생했다. 배포하지 않고 Sol(low)의 해석 뒤 Astra(low)가 화면 문장을 작성하는 고정 구조를 평가했다. 잘못된 문장만 치환하거나 재생성하는 사후 보정은 사용하지 않는다.

다섯 기준 질문의 화면 첫 결론·요약·카드 lead·본문을 모두 확인했다. 다섯 건 모두 응답했고 알려진 화자 오류, 뜻이 반대가 되는 걸림돌 설명, 준비가 없다고 단정하는 오류는 발견하지 못했다.

| 질문 | 실제 결론과 확인점 |
|---|---|
| 재회 | '지금은 다시 연락하기보다 기다림을 멈추는 쪽을 권합니다.' 조회와 답장을 구분 |
| 이직 | '재직 상태에서 새 회사의 급여 지급 여력과 성과 인정 방식을 확인한 뒤 결정'이라고 직접 답함. 사용자 성과의 주체가 유지됨 |
| 친구 | '어떤 행동이 서운했는지 한 번 구체적으로' 말한 뒤 행동을 보라는 답. 사용자가 이미 이유를 물은 점도 반영 |
| 그림 | '자기 스타일의 핵심은 남기고 사람들이 좋아하는 요소를 일부 시험'이라고 첫 문장에서 답함. 상담사의 '제 스타일'로 바뀌지 않음 |
| 해외 | 해외 생활을 포기하지 말고 복귀 조건을 확인한 뒤 선택하라고 답함. 준비 부족을 사실로 만들지 않음 |

이 결과를 보고 작성 규칙을 추가하지 않고, 새 질문 10개와 화자 오류 회귀 1개, 열 장 배열 1개를 최종 검증한다. 새 질문의 예상 판단 기준은 `final-holdout-rubric.md`에 생성 전에 기록했다.

## 비용과 한계

다섯 기준 질문의 API 호출 토큰에 공식 표준 단가를 적용한 추정치를 사용한다. 청구서의 실제 비용이 아니며 캐시 할인·세금·호스팅 비용은 반영하지 않는다. Sol: 입력 $2/1M, 출력 $10/1M. Astra: 입력 $10/1M, 출력 $50/1M. 실제 모델 호출마다 사용량을 남긴다.

- https://developers.openai.com/api/docs/models/gpt-6.1-sol
- https://developers.openai.com/api/docs/models/gpt-6-astra

복잡한 해석을 두 호출로 나누면 지연과 비용이 늘 수 있다. 두 단계는 하나의 78초 생성 예산을 공유하고, 브라우저의 105초 대기 시간 안에 응답하도록 한다. 품질 기준에 미달한 모델로 자동 전환하지 않는다. 이는 오류 시 가용성보다 풀이의 일관성을 우선한 선택이며, 오류가 나도 기존 UI가 질문과 카드를 보존한다.
