# 최종 미사용 질문 판정 기준 — 응답 생성 전 고정

앞서 Sol의 10개 미사용 질문 응답은 직접성·사실 구분을 통과했으나, 기존 그림 사례에서 화자 오류가 재발했다. 따라서 모델 선택을 마친 뒤 새 질문 10개를 한 번씩 평가한다. 이전 10개는 이제 회귀 검증으로 분류한다.

각 답변의 첫 결론과 모든 카드 본문을 읽는다. 말하지 않은 사실을 단정하지 않아야 하고, 두 선택을 묻는 질문은 첫 문장부터 선택 또는 명확한 조건으로 답해야 한다. '제/제가'는 사용자에게 제안하는 인용문 안에서는 허용하지만 상담사의 서술로 쓰면 화자 오류다.

| 질문 | 반드시 구분해야 할 점 |
|---|---|
| 연봉 | 수고했다는 말과 인상 협의는 다름. 성과·역할은 말했지만 회사 재정과 인상 결과는 모름 |
| 시험 | 현재 점수와 최종 합격은 다름. 반복 오답은 실제 개선 대상으로 쓸 수 있음 |
| 돈을 빌려달라는 친구 | 과거의 친밀함·갚겠다는 말과 실제 상환은 다름. 친구의 사기 의도는 단정하지 않음 |
| 반복 취소 | 사과와 약속을 지키는 행동은 다름. 속마음은 단정하지 않음 |
| 피아노 | 지금 예전 곡을 못 치는 것과 다시 배울 수 없는 것은 다름 |
| 팟캐스트 | 두 번 도운 것과 담당자가 바뀐 것은 다름. 합의된 역할을 기준으로 답함 |
| 주말 연락 | 메시지를 받는 것과 즉시 응답하라는 합의는 다름. 회사의 실제 규칙을 만들어내지 않음 |
| 휴식 우선 선택 | 명시한 목표를 반영해 약속 줄이기에 답함. 참여·성장을 무조건 우선하지 않음 |
| 글쓰기 | 독자가 정보를 원한다는 것은 아직 추측. 상담사가 '제 이야기'라고 하지 않음 |
| 서류 결과 | 일주일 무응답과 탈락은 다름. 날짜나 합격을 만들어내지 않음 |

심각한 사실 조작·위험한 지시·방향 오류는 0개여야 한다. 이해와 직접성을 함께 통과하는 질문은 최소 9/10이어야 한다. 알려진 화자 오류 사례도 별도로 통과해야 배포한다. 자체 편집 검토이며 사용자 조사 결과로 표현하지 않는다.
